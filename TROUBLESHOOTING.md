## 🚀 Проблемы с запуском

### ❌ Приложение не запускается (ошибка Windows Defender)

**Симптомы:**
- Windows показывает "Приложение заблокировано"
- "Программа содержит вирусы"
- Hintsage.exe немедленно удаляется

**Причина:** Windows Defender блокирует неподписанные приложения

**Решение:**

1. **Временно отключите Real-time protection:**
   ```
   Windows Security → Virus & threat protection → 
   Manage settings → Real-time protection → Off
   ```

2. **Добавьте в исключения:**
   ```
   Windows Security → Virus & threat protection → 
   Manage settings → Exclusions → Add → Folder →
   Выберите папку с Hintsage.exe
   ```

3. **Нажмите "Подробнее" → "Выполнить в любом случае"**

**Гарантия:** Hintsage.exe абсолютно безопасен и не содержит вирусов.

---

### ❌ Ошибка "Missing DLL" или "Python не найден"

**Симптомы:**
- `python312.dll not found`
- `vcruntime140.dll not found`
- Приложение крашится при запуске

**Причина:** Отсутствуют необходимые библиотеки

**Решение:**

1. **Установите Visual C++ Redistributable:**
   - Скачайте: https://aka.ms/vs/17/release/vc_redist.x64.exe
   - Запустите установщик
   - Перезагрузите ПК

2. **Переустановите приложение:**
   - Удалите старую версию
   - Скачайте свежую версию с [smartsobes.ru](http://smartsobes.ru)

---

### ❌ Приложение запускается, но сразу закрывается

**Симптомы:**
- Окно появляется и исчезает
- Нет overlay окна
- Ничего не происходит

**Причина:** Ошибка инициализации компонентов

**Решение:**

1. **Проверьте лог файл:**
   ```
   logs/hintsage.log
   ```
   Найдите последнюю ошибку `[ERROR]`

2. **Запустите от имени администратора:**
   - ПКМ на Hintsage.exe → "Запустить от имени администратора"

3. **Проверьте config.yaml:**
   - Убедитесь, что файл не поврежден
   - Восстановите из `config.example.yaml`

---

### ❌ "Unable to create process"

**Симптомы:**
- Ошибка при попытке запуска
- "The system cannot execute the specified program"

**Причина:** Файл поврежден или заблокирован

**Решение:**

1. **Проверьте целостность файла:**
   - Размер Hintsage.exe должен быть ~150-200 MB
   - Перекачайте, если размер другой

2. **Разблокируйте файл:**
   - ПКМ на Hintsage.exe → Свойства
   - Внизу: ☑ Разблокировать → Применить

3. **Переместите в другую папку:**
   - Некоторые антивирусы блокируют Downloads
   - Переместите в `C:\Hintsage\`

## 🎤 Проблемы с аудио

### ❌ Микрофон не распознается

**Симптомы:**
- Нажатие `Ctrl + Shift + Q` ничего не делает
- Статус: "Ошибка: Микрофон не найден"
- Нет записи аудио

**Причина:** Микрофон не подключен или не настроен

**Решение:**

1. **Проверьте микрофон в Windows:**
   ```
   Настройки → Система → Звук → Ввод →
   Проверьте, что микрофон отображается
   ```

2. **Установите микрофон по умолчанию:**
   ```
   ПКМ на значок звука → Звуки → Запись →
   ПКМ на микрофон → Использовать по умолчанию
   ```

3. **Разрешите доступ к микрофону:**
   ```
   Настройки → Конфиденциальность → Микрофон →
   Разрешить приложениям доступ к микрофону: Вкл
   ```

4. **Измените `audio.source` в config.yaml:**
   ```yaml
   audio:
     source: "microphone"  # Попробуйте "microphone", "loopback", "both"
   ```

---

### ❌ Качество распознавания плохое

**Симптомы:**
- STT распознает неправильно
- Много ошибок в тексте
- Пропускает слова

**Причина:** Плохое качество аудио или неправильная настройка

**Решение:**

1. **Используйте внешний микрофон:**
   - Встроенный микрофон ноутбука часто дает плохое качество
   - Купите USB микрофон или гарнитуру

2. **Минимизируйте фоновый шум:**
   - Закройте окна
   - Выключите вентиляторы/кондиционеры
   - Используйте тихое помещение

3. **Говорите четче:**
   - Не спешите
   - Делайте паузы между словами
   - Говорите громче (но не кричите)

4. **Обновитесь до PRO:**
   - Whisper GPU гораздо точнее Vosk
   - Лучше обрабатывает акценты и шум

---

### ❌ "Audio device already in use"

**Симптомы:**
- Ошибка: "Аудио устройство занято"
- Микрофон не захватывается
- Конфликт с другими приложениями

**Причина:** Другое приложение использует микрофон

**Решение:**

1. **Закройте приложения, использующие микрофон:**
   - Zoom, Skype, Discord, Teams
   - Игры с voice chat
   - Другие recording приложения

2. **Перезапустите аудио службу Windows:**
   ```
   Win + R → services.msc → Enter
   Найдите "Windows Audio" → ПКМ → Перезапустить
   ```

3. **Перезагрузите ПК**

---

### ❌ Loopback не работает

**Симптомы:**
- `audio.source: "loopback"` не захватывает звук
- Нет распознавания системного аудио

**Причина:** Loopback device не настроен

**Решение:**

1. **Установите Stereo Mix (если есть):**
   ```
   ПКМ на значок звука → Звуки → Запись →
   ПКМ на пустом месте → Показать отключенные устройства →
   ПКМ на Stereo Mix → Включить
   ```

2. **Или используйте Virtual Cable:**
   - Скачайте VB-Audio Virtual Cable
   - Установите
   - В config.yaml используйте `"loopback"`

3. **Или используйте `"both"`:**
   ```yaml
   audio:
     source: "both"  # Попробует loopback, fallback на microphone
   ```

## 🤖 Проблемы с AI генерацией

### ❌ "OpenAI API Error: 401 Unauthorized"

**Симптомы:**
- Ошибка: "Неверный API ключ"
- Ответы не генерируются
- Статус: красный

**Причина:** API ключ невалиден или expired

**Решение:**

**На FREE/PRO тарифах:**
- API ключи встроены в приложение
- Обновите до последней версии
- Это не должно происходить — свяжитесь с поддержкой

**Если используете свой ключ (advanced):**
1. Проверьте баланс OpenAI аккаунта
2. Обновите ключ в настройках
3. Убедитесь, что ключ не заблокирован

---

### ❌ "OpenAI API Error: 403 Forbidden"

**Симптомы:**
- Ошибка: "Country, region, or territory not supported"
- Не работает из России/Китая/и др.

**Причина:** OpenAI API блокирует ваш регион

**Решение:**

1. **Включите VPN:**
   - Используйте VPN с серверами в США/Европе
   - Убедитесь, что VPN активен ПЕРЕД запуском Hintsage
   - Проверьте IP: https://www.whatismyip.com

2. **Рекомендуемые VPN:**
   - ExpressVPN (быстрый, стабильный)
   - NordVPN (много серверов)
   - Proton VPN (бесплатный тариф)

3. **Перезапустите приложение после включения VPN**

---

### ❌ "OpenAI API Error: 429 Too Many Requests"

**Симптомы:**
- Ошибка: "Слишком много запросов"
- Лимит превышен

**Причина:** Превышен лимит запросов

**Решение:**

**На FREE тарифе:**
- Подождите 1 час (лимит: 5 запросов/час)
- Или купите PRO (безлимитные запросы)

**На PRO тарифе:**
- Это не должно происходить
- Свяжитесь с поддержкой

---

### ❌ Ответы генерируются медленно (>30 секунд)

**Симптомы:**
- Долгое ожидание ответа
- Статус "Генерация..." висит долго

**Причина:** Медленный интернет или удаленный VPN

**Решение:**

1. **Проверьте скорость интернета:**
   - https://www.speedtest.net
   - Минимум: 5 Mbps download / 1 Mbps upload

2. **Выберите ближайший VPN сервер:**
   - Европа (для России)
   - Восточное побережье США
   - Азия (для Азии)

3. **Попробуйте позже:**
   - OpenAI API может быть перегружен
   - Пиковые часы: 9:00-18:00 MSK

---

### ❌ Ответы нерелевантные или глупые

**Симптомы:**
- GPT-4 генерирует бред
- Ответы не по теме
- Галлюцинации

**Причина:** Плохой промпт или контекст

**Решение:**

1. **Очистите контекст:**
   - `Ctrl + Shift + C`
   - Начните новую сессию

2. **Проверьте качество вопроса:**
   - Убедитесь, что STT правильно распознал
   - Перефразируйте вопрос

3. **Измените профиль промпта:**
   - В config.yaml выберите другой `default_profile`
   - Доступно: backend, frontend, devops, data_science, mobile, qa

4. **Настройте промпт (PRO):**
   - Откройте config.yaml
   - Измените `prompts.profiles.{your_profile}.system_message`

## 🖥️ Проблемы с интерфейсом

### ❌ Overlay окно не отображается

**Симптомы:**
- Приложение запущено, но overlay не виден
- Нет окна на экране

**Причина:** Overlay скрыт, за другими окнами, или неправильная позиция

**Решение:**

1. **Проверьте, что приложение запущено:**
   - Диспетчер задач → Процессы → Hintsage.exe

2. **Попробуйте показать overlay:**
   - Нажмите `Ctrl + Shift + O` (show overlay)
   - Или перезапустите приложение

3. **Измените позицию:**
   - Откройте config.yaml
   - Измените `ui.overlay.position`:
     ```yaml
     ui:
       overlay:
         position: "top-left"  # Или "top-right", "bottom-left", "bottom-right"
     ```

4. **Проверьте прозрачность:**
   ```yaml
   ui:
     overlay:
       opacity: 1.0  # Максимальная непрозрачность
   ```

---

### ❌ Overlay окно не всегда поверх всех окон

**Симптомы:**
- Overlay скрывается за браузером/другими окнами
- Не "Always on Top"

**Причина:** Конфликт с другими Always on Top приложениями

**Решение:**

1. **Закройте другие Always on Top приложения:**
   - PowerToys FancyZones
   - DisplayFusion
   - Другие overlay утилиты

2. **Перезапустите Hintsage**

3. **Используйте второй монитор:**
   - Overlay на втором мониторе всегда видно

---

### ❌ Текст в overlay не читается (слишком мелкий/крупный)

**Симптомы:**
- Шрифт слишком маленький
- Шрифт слишком большой
- Не помещается в окно

**Причина:** Размер окна или масштабирование Windows

**Решение:**

1. **Измените размер overlay:**
   ```yaml
   ui:
     overlay:
       width: 500   # Увеличьте ширину
       height: 700  # Увеличьте высоту
   ```

2. **Проверьте масштабирование Windows:**
   ```
   Настройки → Система → Дисплей →
   Масштаб → 100% (рекомендуется)
   ```

3. **Измените шрифт** (advanced):
   - Откройте `modules/ui_overlay/overlay_window.py`
   - Найдите `QFont("Consolas", 11)`
   - Измените размер: `QFont("Consolas", 14)`

---

### ❌ Overlay не скрывается от screen capture

**Симптомы:**
- Zoom/Teams видит overlay
- Скриншоты захватывают overlay

**Причина:** Anti-screenshot не работает (Windows < 10 2004)

**Решение:**

1. **Обновите Windows до последней версии:**
   ```
   Настройки → Обновление и безопасность → 
   Проверить наличие обновлений
   ```

2. **Используйте Windows 10 2004+ или Windows 11**

3. **Или используйте физическое решение:**
   - Второй монитор для overlay
   - Камера направлена только на первый монитор

## ⚡ Проблемы с производительностью

### ❌ Приложение использует 100% CPU

**Симптомы:**
- ПК тормозит
- Высокая нагрузка на процессор
- Вентиляторы шумят

**Причина:** STT или OCR обработка

**Решение:**

1. **Это нормально во время обработки:**
   - Whisper STT нагружает CPU/GPU
   - EasyOCR тоже
   - После завершения нагрузка спадет

2. **Закройте другие приложения:**
   - Браузер с многочисленными вкладками
   - Игры
   - Видеоредакторы

3. **Понизьте приоритет:**
   ```
   Диспетчер задач → Подробности →
   ПКМ на Hintsage.exe → Приоритет → Ниже среднего
   ```

---

### ❌ Приложение использует много RAM (>4GB)

**Симптомы:**
- Высокое использование памяти
- ПК тормозит
- "Out of memory"

**Причина:** Whisper/EasyOCR модели загружены в память

**Решение:**

1. **Это нормально для PRO тарифа:**
   - Whisper model: ~2 GB
   - EasyOCR model: ~1 GB
   - Приложение: ~1 GB

2. **Вернитесь на FREE:**
   - Vosk model: ~200 MB (намного меньше)

3. **Увеличьте RAM:**
   - Минимум 8 GB для PRO

---

### ❌ GPU не используется (PRO тариф)

**Симптомы:**
- Whisper работает медленно
- GPU Utilization 0%

**Причина:** CUDA не установлена или не обнаружена

**Решение:**

1. **Проверьте NVIDIA драйвера:**
   ```
   Win + R → cmd → nvidia-smi
   Должен показать вашу видеокарту
   ```

2. **Установите CUDA Toolkit 11.8:**
   - https://developer.nvidia.com/cuda-11-8-0-download-archive

3. **Перезапустите приложение**

4. **Проверьте лог:**
   ```
   logs/hintsage.log → Ищите "CUDA" или "GPU"
   ```
