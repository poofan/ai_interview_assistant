# 🚀 Первый запуск Hintsage

Пошаговая инструкция для первого запуска.

## Шаг 1: Подготовка (5 минут)

### 1.1 Установка зависимостей

Откройте командную строку в папке проекта:

```bash
# Активируйте виртуальное окружение
venv\Scripts\activate

# ИЛИ используйте автоматический установщик
install.bat
```

### 1.2 Скачайте Vosk модель

1. Перейдите: https://alphacephei.com/vosk/models
2. Скачайте **vosk-model-small-ru-0.22.zip** (~150 MB)
3. Распакуйте в папку `models/`

Должно получиться:
```
models/
  └── vosk-model-small-ru-0.22/
      ├── am/
      ├── conf/
      ├── graph/
      └── ivector/
```

### 1.3 Настройте конфигурацию

```bash
# Скопируйте пример
copy config.example.yaml config.yaml

# Откройте в блокноте
notepad config.yaml
```

**Обязательно измените:**
```yaml
openai:
  api_key: "sk-ваш-ключ-здесь"  # ← Вставьте ваш OpenAI API ключ
```

Получить ключ: https://platform.openai.com/api-keys

## Шаг 2: Тестирование модулей (опционально)

Проверьте, что все модули работают:

```bash
python test_modules.py
```

Вы должны увидеть:
```
=== Тест 1: Импорт модулей ===
✅ config_manager
✅ llm_integration
✅ context_manager
...
✅ Тестирование завершено!
```

## Шаг 3: Первый запуск!

```bash
python main.py
```

### Что должно произойти:

1. **Загрузка модулей** (10-30 секунд):
   ```
   ============================================================
   🧠 Hintsage - AI Interview Assistant
   Архитектура: Онтология 'Ясна'
   ============================================================
   Инициализация компонентов...
   ✅ ConfigManager инициализирован
   ✅ LLM Client инициализирован (модель: gpt-4o)
   ✅ ContextManager инициализирован
   ...
   ```

2. **Появится overlay окно** в правом верхнем углу экрана

3. **Начнется захват аудио** с микрофона

4. **Статус**: "✅ Готов к работе" (зеленым)

## Шаг 4: Первый тест

### Тест 1: Автоматическая детекция

1. **Говорите в микрофон**: "Что такое Python?"
2. **Дождитесь распознавания** (в консоли появится: `📝 Распознано: что такое python`)
3. **Детектор обнаружит вопрос**: `🔔 Триггер вопроса!`
4. **Статус изменится**: "⏳ Генерация ответа..."
5. **Получите ответ** в overlay окне!

### Тест 2: Ручной триггер

Если автоматика не сработала:

1. **Задайте вопрос вслух**: "Как работает GIL в Python?"
2. **Нажмите `Ctrl+Shift+Q`** (или кнопку "Триггер")
3. **Дождитесь ответа**

### Тест 3: Скриншот + OCR

1. Откройте код или вопрос в браузере
2. Нажмите **`Ctrl+Shift+S`**
3. Приложение захватит экран, распознает текст и даст объяснение

## Возможные проблемы при первом запуске

### ❌ "Vosk модель не найдена"

**Решение:**
```bash
# Проверьте путь в config.yaml:
stt:
  vosk:
    model_path: "models/vosk-model-small-ru-0.22"

# Убедитесь, что папка существует:
dir models\vosk-model-small-ru-0.22
```

### ❌ "OpenAI API ключ неверный"

**Решение:**
1. Проверьте ключ в `config.yaml`
2. Убедитесь, что у вас есть кредиты: https://platform.openai.com/account/billing
3. Проверьте, что ключ начинается с `sk-`

### ❌ "Микрофон не работает"

**Решение:**
1. Проверьте, что микрофон подключен
2. Дайте разрешение Python на доступ к микрофону (Windows Settings)
3. Посмотрите список устройств:
   ```python
   # В консоли Python:
   from modules.audio_capture import AudioCapture
   ac = AudioCapture()
   ac.list_devices()
   ```

### ❌ "Overlay окно не появляется"

**Решение:**
1. Проверьте логи: `logs/hintsage.log`
2. Попробуйте изменить позицию в config.yaml:
   ```yaml
   ui:
     overlay:
       position: "top-left"  # вместо top-right
   ```

### ❌ "EasyOCR долго загружается"

**Решение:**
- Это нормально при первом запуске (~100 MB моделей)
- Или переключитесь на Tesseract:
  ```yaml
  screenshot:
    ocr_engine: "tesseract"
  ```

## Шаг 5: Настройка под себя

### Измените системный промпт

В `config.yaml`:
```yaml
openai:
  system_prompt: "Ты - эксперт по [ваша специализация]. Отвечай кратко и с примерами кода на [язык программирования]."
```

### Добавьте свои вопросительные паттерны

```yaml
question_detector:
  patterns:
    - "расскажи про"
    - "в чем разница между"
    - "можешь объяснить"
```

### Настройте позицию и прозрачность

```yaml
ui:
  overlay:
    position: "bottom-right"  # top-left, top-right, bottom-left, bottom-right
    opacity: 0.85             # 0.0 - 1.0
    width: 500
    height: 700
```

## Шаг 6: Проверка антидетекта (важно!)

### Тест невидимости:

1. **Запустите Hintsage**
2. **Откройте Zoom/Teams** (или другую программу для screen share)
3. **Начните демонстрацию экрана**
4. **Проверьте** на втором устройстве/в записи:
   - Overlay окно не должно быть видно
   - Если видно - проверьте версию Windows (требуется 10 2004+)

### Проверка версии Windows:

```cmd
winver
```

Должно быть: **Windows 10 версия 2004 или новее**

## Шаг 8: Завершение работы

### Правильное завершение:

1. Нажмите кнопку `×` в overlay окне
2. ИЛИ нажмите `Ctrl+Q`
3. История автоматически сохранится в `data/sessions/`

### Очистка после собеседования:

```bash
# Удалить историю сессий
del data\sessions\*.json

# Удалить логи
del logs\*.log
```

## Горячие клавиши (запомните!)

| Клавиша | Действие |
|---------|----------|
| `Ctrl+Shift+Q` | Ручной триггер вопроса |
| `Ctrl+Shift+S` | Скриншот + OCR |
| `Ctrl+Shift+C` | Очистить контекст |
| `Esc` | Скрыть/показать окно |
| `Ctrl+Q` | Выход |
