## 💡 **Ключевые особенности:**

### **1. Completion Order для UI**
- Ответы появляются **по мере готовности**
- Пользователь видит результат **максимально быстро**

### **2. FIFO для контекста**
- Контекст для LLM сохраняет **правильный порядок**
- Используется `answer_buffer` для буферизации
- Добавляется в контекст только по порядку

### **3. Параллельная обработка**
- До **3 запросов одновременно**
- QThreadPool управляет потоками
- Thread-safe через PyQt6 сигналы/слоты

## ⚠️ **Известные ограничения:**

1. **Лимит очереди:** 10 запросов одновременно
   - При превышении выдается ошибка
   - Защищает от перегрузки GPU/API

2. **GPU память:**
   - 3 параллельных Whisper могут потребовать ~3-4 ГБ VRAM
   - При необходимости снизить `max_workers` до 2

3. **OpenAI API limits:**
   - Rate limits не реализованы
   - При превышении лимита будут ошибки от API

## 🔧 **Настройка производительности:**

### **Для слабого GPU:**
```yaml
parallel:
  max_workers: 2  # Вместо 3
```

### **Для быстрого GPU:**
```yaml
parallel:
  max_workers: 4  # Больше параллелизма
```

### **Отключить многопоточность:**
```yaml
parallel:
  enabled: false  # Вернется к синхронной обработке
```
