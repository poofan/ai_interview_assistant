## 🌟 Общие вопросы

### Что такое Hintsage?

**Hintsage** — это AI-ассистент для прохождения технических интервью. Приложение в реальном времени распознает вопросы (голосовые или текстовые) и генерирует подсказки с помощью GPT-4, отображая их в незаметном overlay окне.

### Для кого это приложение?

- 👨💻 **Разработчики** — готовящиеся к техническим интервью
- 🎓 **Студенты** — сдающие экзамены или защищающие проекты
- 🚀 **Специалисты** — переходящие на новую должность
- 🔄 **Карьеристы** — меняющие сферу деятельности

### Легально ли использовать Hintsage?

Hintsage — это инструмент для **подготовки** и **обучения**. Использование на реальных интервью зависит от политики компании и законодательства вашей страны. Мы рекомендуем использовать приложение в учебных целях.

**Внимание:** Мы не несем ответственности за последствия использования приложения на реальных интервью.

### Есть ли пробный период?

Да! **FREE тариф** доступен бессрочно без ограничений по времени. Вы можете протестировать базовый функционал бесплатно, а затем перейти на PRO для расширенных возможностей.

### Нужен ли интернет для работы?

**Да**, стабильное интернет-соединение необходимо для:
- Генерации ответов через OpenAI GPT-4 API
- Авторизации и проверки подписки
- Проверки обновлений

**Оффлайн работа** в планах для будущих версий.

## 💾 Установка и запуск

### Как установить Hintsage?

1. Зарегистрируйтесь на [smartsobes.ru](http://smartsobes.ru)
2. Войдите в личный кабинет
3. Скачайте `Hintsage.exe`
4. Запустите файл (от имени администратора, если требуется)

**Не требуется установка** — приложение работает как portable.

### Почему Windows Defender блокирует приложение?

Это нормально для новых приложений без цифровой подписи Microsoft. 

**Решение:**
1. Нажмите "Подробнее"
2. Нажмите "Выполнить в любом случае"
3. Добавьте Hintsage в исключения антивируса

Приложение абсолютно безопасно и не содержит вирусов.

### Как запустить приложение в фоновом режиме?

Hintsage автоматически запускается в фоновом режиме. Overlay окно можно:
- Минимизировать (`_` кнопка)
- Скрыть (`Ctrl + Shift + H`)
- Закрыть (`×` кнопка)

### Можно ли запускать несколько экземпляров?

Нет, приложение позволяет запустить только один экземпляр. Это сделано для предотвращения конфликтов с горячими клавишами и аудио-устройствами.

## ⚙️ Функциональность

### Как работает распознавание речи?

Hintsage использует два STT движка:
- **Vosk** (FREE) — быстрый, оффлайн-ready
- **Whisper GPU** (PRO/ENTERPRISE) — лучшее качество

Нажмите `Ctrl + Shift + Q` для захвата аудио. Приложение:
1. Записывает аудио с микрофона/loopback
2. Распознает речь через STT движок
3. Фильтрует галлюцинации
4. Отправляет текст в GPT-4

### Как работает OCR скриншотов?

На PRO/ENTERPRISE тарифах доступен OCR:
1. Нажмите `Ctrl + Shift + S`
2. Приложение сделает скриншот экрана
3. EasyOCR распознает текст (GPU ускорение)
4. Текст отправится в GPT-4

**Поддерживаемые языки:** Русский, Английский

### Что такое контекст?

**Контекст** — это история предыдущих вопросов и ответов, которую приложение помнит. Это позволяет GPT-4 давать более релевантные ответы.

**Лимиты контекста:**
- FREE: 10 сообщений
- PRO: 30 сообщений
- ENTERPRISE: 30 сообщений

Очистите контекст `Ctrl + Shift + C` перед новой темой.

### Можно ли настроить промпты?

Да, на PRO/ENTERPRISE тарифах:
1. Откройте `config.yaml`
2. Найдите секцию `prompts.profiles`
3. Измените профили под свои нужды

**Профили:** Backend, Frontend, DevOps, Data Science, Mobile, QA

### Как работает защита от скриншотов?

Hintsage использует Windows API `SetWindowDisplayAffinity` для исключения overlay окна из захвата:
- ✅ Не виден на скриншотах Windows
- ✅ Не виден в Zoom/Teams/Skype screen share
- ✅ Не захватывается OBS/XSplit

**Внимание:** Физическая камера все еще может его увидеть!

### Работает ли на macOS/Linux?

**Нет**, пока только Windows 10/11.

**macOS/Linux поддержка** в планах для версии 2.0.

## 🖥️ Технические требования

### Нужна ли видеокарта NVIDIA?

**FREE тариф:** Нет, работает на любом ПК (Vosk STT работает на CPU)

**PRO/ENTERPRISE:** Рекомендуется NVIDIA GPU для максимальной скорости:
- Whisper STT: GTX 1060+ (6GB VRAM)
- EasyOCR: GTX 1050+ (4GB VRAM)

Приложение автоматически адаптируется под ваше железо.

### Сколько оперативной памяти нужно?

- **Минимум:** 4 GB RAM
- **Рекомендуется:** 8 GB RAM
- **Оптимально:** 16 GB RAM (для PRO с GPU)

### Какой процессор нужен?

- **Минимум:** Intel Core i3 / AMD Ryzen 3
- **Рекомендуется:** Intel Core i5 / AMD Ryzen 5
- **Оптимально:** Intel Core i7 / AMD Ryzen 7

### Сколько трафика потребляет приложение?

**Очень мало:**
- Авторизация: ~10 KB
- Один запрос к GPT-4: 5-20 KB
- Проверка обновлений: ~5 KB

**В среднем:** 1-5 MB за интервью (10-20 запросов)

## 🔐 Безопасность и конфиденциальность

### Безопасно ли использовать Hintsage?

**Да!** Приложение:
- ✅ Не содержит вирусов/малвари
- ✅ Не крадет данные
- ✅ Не устанавливает шпионское ПО
- ✅ Не передает данные третьим лицам

### Что вы делаете с моими данными?

Мы **НЕ храним:**
- ❌ Аудио записи
- ❌ Скриншоты
- ❌ Содержимое вопросов и ответов
- ❌ История интервью

Мы **храним только:**
- ✅ Email и хэш пароля
- ✅ Информацию о подписке
- ✅ Логи использования (анонимно)

**Все данные шифруются** при передаче (HTTPS/TLS 1.3).

### Можно ли использовать в корпоративной сети?

Да, но убедитесь, что:
- Разрешены исходящие HTTPS соединения
- Не блокируется OpenAI API (api.openai.com)
- Не блокируется наш backend (smartsobes.ru)

### Как работает VPN с Hintsage?

**Если вы в России**, OpenAI API может быть заблокирован. Используйте VPN:
- Включите VPN перед запуском приложения
- Убедитесь, что VPN стабилен
- Рекомендуем: Европа, США (низкая задержка)

### Есть ли аналитика/трекинг?

**Нет!** Мы не используем:
- ❌ Google Analytics
- ❌ Яндекс.Метрика
- ❌ Telemetry
- ❌ Crash reporters

Только базовые логи для отладки (локально).

## 🔧 Решение проблем

### Приложение не запускается

**Причины:**
1. Windows 7/8 (не поддерживается)
2. Антивирус блокирует
3. Нет прав администратора
4. Поврежденный файл

**Решение:**
1. Проверьте Windows 10/11
2. Добавьте в исключения антивируса
3. Запустите от имени администратора
4. Пере скачайте файл

### Не работает распознавание речи

**Причины:**
1. Микрофон не подключен/выключен
2. Микрофон занят другим приложением
3. Неправильные настройки аудио

**Решение:**
1. Проверьте микрофон в Windows
2. Закройте Zoom/Skype/Discord
3. Измените `audio.source` в config.yaml

### Не генерируются ответы

**Причины:**
1. Нет интернета
2. OpenAI API заблокирован (Россия)
3. Лимит запросов превышен (FREE)

**Решение:**
1. Проверьте соединение
2. Включите VPN
3. Подождите 1 час / купите PRO

### Overlay не отображается

**Причины:**
1. Overlay скрыт/минимизирован
2. Неправильная позиция
3. Overlay за другими окнами

**Решение:**
1. Перезапустите приложение
2. Измените позицию в config.yaml
3. Нажмите `Ctrl + Shift + O` (показать overlay)

### Низкая скорость генерации

**Причины:**
1. Медленный интернет
2. Удаленный VPN сервер
3. Высокая нагрузка OpenAI API

**Решение:**
1. Проверьте скорость интернета
2. Выберите ближайший VPN сервер
3. Попробуйте позже

### Приложение крашится

**Причины:**
1. Недостаточно RAM
2. Конфликт с другими приложениями
3. Баг в приложении

**Решение:**
1. Закройте другие программы
2. Обновите приложение
3. Отправьте лог на support@smartsobes.ru

**Лог файл:** `logs/hintsage.log`
