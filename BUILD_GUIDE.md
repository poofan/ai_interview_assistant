# 📦 Руководство по сборке Hintsage в .exe

> **Цель:** Собрать одиночный .exe файл для распространения без Python

---

## 🎯 Зачем нужна сборка?

**Преимущества .exe:**
- ✅ **Простота распространения** - один файл вместо 100+ зависимостей
- ✅ **Не нужен Python** - работает на любом Windows
- ✅ **Защита кода** - скомпилированный формат сложнее декомпилировать
- ✅ **Профессиональный вид** - как настоящее приложение
- ✅ **Готовность к коммерциализации** - основа для платной версии

---

## 🛠️ Процесс сборки

### **Шаг 1: Подготовка**

1. **Активируйте виртуальное окружение:**
   ```bash
   venv\Scripts\activate
   ```

2. **Установите PyInstaller:**
   ```bash
   pip install pyinstaller
   ```

3. **Проверьте что всё работает:**
   ```bash
   python main.py
   ```
   > Если есть ошибки - сначала исправьте их!

---

### **Шаг 2: Запуск сборки**

**Просто запустите:**
```bash
build.bat
```

**Что произойдет:**
```

[2/4] Очистка старых сборок...     ✅
[3/4] Сборка приложения...         ⏳ 5-10 минут
[4/4] Проверка результата...       ✅
```

## ⚙️ Конфигурация сборки

### **Файл: hintsage.spec**

Это спецификация для PyInstaller. Основные параметры:

```python
# Режим сборки
console=False           # БЕЗ консоли (silent mode)

# Сжатие
upx=True               # UPX сжатие (~30% меньше)

# Включаемые файлы
datas=[
    ('config.yaml', '.'),
    ('models', 'models'),
]

# Hidden imports (для динамических импортов)
hiddenimports=[
    'torch.cuda',
    'faster_whisper',
    'easyocr',
]
```

**Редактируйте `hintsage.spec` если нужно:**
- Добавить иконку: `icon='icon.ico'`
- Включить консоль для debug: `console=True`
- Добавить файлы: `datas += [('my_file.txt', '.')]`

## 🐛 Troubleshooting

### **Проблема 1: Ошибка "Module not found"**

**Решение:** Добавьте модуль в `hiddenimports` в `hintsage.spec`:
```python
hiddenimports += ['missing_module_name']
```

Пересоберите:
```bash
build.bat
```

---

### **Проблема 2: .exe не запускается**

**Диагностика:**
1. Измените `console=True` в `hintsage.spec`
2. Пересоберите
3. Запустите `dist\Hintsage.exe` из консоли
4. Смотрите вывод ошибок

**Частые причины:**
- ❌ Не найден config.yaml → скопируйте рядом с .exe
- ❌ Не найдены модели Vosk → проверьте папку `models/`
- ❌ CUDA не найдена → установите CUDA Toolkit

---

### **Проблема 3: Слишком большой файл (>1GB)**

**Решение:**
1. Исключите ненужные модули в `hintsage.spec`:
   ```python
   excludes=['matplotlib', 'scipy', 'pandas']
   ```

2. Используйте `--onefile` вместо `--onedir`
3. Включите UPX сжатие: `upx=True`

---

### **Проблема 4: Антивирус блокирует**

**Причина:** PyInstaller exe часто ложно определяются как вирусы

**Решение:**
1. Добавьте в исключения антивируса
2. Или подпишите .exe цифровой подписью (для production)

## 📝 Debug режим

### **Для отладки сборки:**

1. **Включите консоль:**
   ```python
   # hintsage.spec
   console=True  # было False
   ```

2. **Включите debug:**
   ```python
   # hintsage.spec
   debug=True    # было False
   ```

3. **Пересоберите:**
   ```bash
   pyinstaller --clean hintsage.spec
   ```

4. **Запустите и смотрите вывод:**
   ```bash
   dist\Hintsage.exe
   ```
