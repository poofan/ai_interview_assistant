### **2. Model Manager** (`modules/models/model_manager.py`)

Менеджер загрузки моделей:

**Функции:**
- ✅ Проверка наличия моделей
- ✅ Загрузка недостающих моделей
- ✅ Валидация целостности
- ✅ Прогресс бар загрузки
- ✅ Управление версиями

**Методы:**
```python
# Проверить какие модели нужны
missing = model_manager.get_missing_models("pro")

# Загрузить модель
model_manager.download_model("whisper-small", progress_callback)

# Загрузить все недостающие
model_manager.download_missing_models("pro", progress_callback)
```

PyQt6 диалог с прогресс баром:

**Features:**
- ✅ Список моделей для загрузки

- ✅ Лог загрузки
- ✅ Автоматическое закрытие после завершения

## 🔄 **WORKFLOW:**

### **Первый запуск (FREE tier):**

```
1. User downloads Hintsage.exe (~200 MB)
   ↓
2. Запускает .exe
   ↓
3. Model Manager проверяет: нет моделей для FREE

4. Показывается диалог: "Загрузить Vosk (~200 MB)?"
```

## 🛠️ **РЕАЛИЗАЦИЯ:**

### **Файлы:**

```
modules/
└── models/
    ├── __init__.py
    └── model_manager.py        # ModelManager + Dialog

models/
└── model_registry.json         # JSON манифест

hintsage.spec                   # PyInstaller (БЕЗ моделей!)
main.py                         # Интеграция check_and_download_models()
```

### **Интеграция в main.py:**

```python
# В _init_components():
def _init_components(self):
    ...
    # Feature Manager
    self.feature_manager = FeatureManager(tier="free")
    
    # Model Manager - проверка и загрузка
    self._check_and_download_models()  # <- НОВОЕ!
    ...

# Новый метод:
def _check_and_download_models(self):
    model_manager = ModelManager()
    tier = self.feature_manager.tier
    
    missing = model_manager.get_missing_models(tier)
    if missing:
        dialog = ModelDownloadDialog(model_manager, tier)
        dialog.exec()
```

### **PyInstaller config:**

```python
# hintsage.spec

# БЫЛО:
# datas += [('models', 'models')]  # Все модели = 2+ GB

# СТАЛО:
datas += [
    ('models/model_registry.json', 'models'),  # Только манифест!
]
# Модели НЕ включаются, загружаются при первом запуске!
```
