# 🧠 Hintsage - AI Interview Assistant

**Кодовое имя:** Hintsage  
**Концепция:** Невидимый AI-ассистент для онлайн-собеседований и лайвкодинга

## 🎯 Описание

Десктопный AI-ассистент, который:
- 🎤 Слушает аудио во время собеседования
- 📝 Переводит речь в текст (STT)
- 🤖 Автоматически определяет вопросы
- 💬 Генерирует ответы через OpenAI GPT
- 👻 Невидим для собеседника (антидетект)
- 🖥️ Показывает ответы через overlay-окно

## 🏗️ Архитектура (по онтологии "Ясна")

Проект построен по принципу **"Функция = Архетип"**:

```
hintsage/
├── modules/
│   ├── audio_capture/      # [ВЕДИ + ИЖЕ] - захват аудиопотока
│   ├── stt/                # [МЫСЛЕТЕ + ВЕДИ] - преобразование речи в текст
│   ├── question_detector/  # [ЧЕЛО + МЫСЛЕТЕ] - определение вопросов
│   ├── context_manager/    # [ПАМЯТЬ + ДОБРО] - управление историей
│   ├── llm_integration/    # [РЦИ + ИЖЕ] - OpenAI API
│   ├── security/           # [ШТОР + ТАЙНА] - антидетект
│   ├── ui_overlay/         # [ЛИЧЬ + ЧЕЛО] - интерфейс
│   ├── teleprompter/       # [ЛИЧЬ + СЛОВО] - телесуфлёр
│   ├── syntax_highlighter/ # [МЫСЛЕТЕ + ЛИЧЬ] - подсветка кода
│   ├── screenshot_ocr/     # [ВЕДИ + МЫСЛЕТЕ] - скриншоты и OCR
│   └── config_manager/     # [ДОБРО + АЗ] - конфигурация
├── main.py                 # Точка входа
├── requirements.txt        # Зависимости
└── config.example.yaml     # Пример конфигурации
```

## 🚀 Установка

```bash
# Клонировать репозиторий
git clone <repo-url>
cd ai_interview_assistant

# Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt

# Скопировать и настроить конфигурацию
copy config.example.yaml config.yaml
# Добавить ваш OpenAI API ключ в config.yaml
```

## 🎮 Использование

### **Вариант 1: Через готовый скрипт (рекомендуется)** ✨

```bash
# Windows - просто двойной клик на файл:

start_silent.vbs       # БЕЗ консоли (невидимый запуск) ⭐ РЕКОМЕНДУЕТСЯ
start_background.bat   # Фоновый режим (консоль закрывается)
start.bat              # С консолью (для отладки)
start_quick.bat        # Быстрый запуск с консолью
```

**Для интервью используйте `start_silent.vbs`** - полностью невидимый запуск!

### **Вариант 2: Через командную строку**

```bash
# Активировать venv и запустить
venv\Scripts\activate
python main.py
```

### **Вариант 3: Прямой запуск**

```bash
venv\Scripts\python.exe main.py
```

---

### ⌨️ Горячие клавиши (работают глобально):
- `Ctrl+Shift+H` - Показать/скрыть окно overlay
- `Ctrl+Shift+Q` - Распознать последние 10 сек речи
- `Ctrl+Shift+S` - Скриншот области + OCR (GPU)
- `Ctrl+Shift+C` - Очистить контекст диалога
- `Ctrl+Shift+X` - Выход из приложения
- `Esc` - Быстро скрыть окно (локальная)

## ⚙️ Конфигурация

В файле `config.yaml`:
- OpenAI API ключ
- Выбор STT модели (Vosk/Whisper)
- Настройки overlay (прозрачность, позиция)
- Параметры детекции вопросов
- Режимы безопасности

## 🛡️ Безопасность

- ✅ Не попадает на скриншоты
- ✅ Не видно в screen share
- ✅ Не перехватывает фокус
- ✅ Локальное хранение API ключей
- ✅ Бесшумный режим

## 📦 Требования

- Windows 10/11 (основная поддержка)
- OpenAI API ключ
