# 🎯 Профили промптов и языки программирования

## Универсальная поддержка языков!

Hintsage теперь **не завязан на Python** - поддерживает любой язык программирования!

## 🔧 Настройка языка

В `config.yaml`:

```yaml

  default_profile: "algorithms"      # Тип собеседования
  programming_language: "Java"       # ← ВАШ язык
  auto_detect_language: true         # Автоопределение
```

## 🎭 Профили собеседований

### 1️⃣ **ALGORITHMS** (Алгоритмы)

**Когда использовать:** LeetCode, алгоритмические задачи, структуры данных

**Что делает:**
- ✅ Генерирует **ГОТОВЫЙ КОД** с решением
- ✅ Добавляет комментарии
- ✅ Указывает сложность O(n)
- ✅ Краткое объяснение подхода

**Пример вопроса:**
```
"Напиши функцию для поиска в бинарном дереве"
```

**Ответ на Java:**
```java
public TreeNode searchBST(TreeNode root, int val) {
    // Базовый случай
    if (root == null || root.val == val) {
        return root;
    }
    
    // Рекурсивный поиск
    return val < root.val 
        ? searchBST(root.left, val)
        : searchBST(root.right, val);
}

Сложность: O(h) где h - высота дерева
Подход: Используем свойство BST для направленного поиска
```

## 🤖 Автоопределение языка

### Как работает:

Hintsage **автоматически определяет** язык программирования из вопроса!

**Пример 1:**
```
Вопрос: "Как в Java реализовать HashMap?"
         ↓
Определен язык: Java
         ↓
Ответ: [код на Java]
```

**Пример 2:**
```
Вопрос: "Напиши binary search на C++"
         ↓
Определен язык: C++
         ↓
Ответ: [код на C++]
```

**Пример 3:**
```
Вопрос: "Реализуй sorted map" (язык не указан)
         ↓
Используется default: Java (из config.yaml)
         ↓
Ответ: [код на Java]
```

### Паттерны автоопределения:

| Язык | Ключевые слова |
|------|----------------|
| Java | `Java`, `class`, `public static`, `System.out` |
| C++ | `C++`, `std::`, `#include`, `iostream` |
| JavaScript | `JavaScript`, `const`, `let`, `=>`, `npm` |
| Go | `Golang`, `Go`, `func`, `package main` |
| Python | `Python`, `def`, `import`, `print(` |

## 🎯 Автопереключение профиля

Hintsage **автоматически определяет тип вопроса** и переключает профиль!

**Примеры:**

### Вопрос 1 (алгоритм):
```
"Напиши функцию для сортировки массива"
↓
Профиль: ALGORITHMS
Промпт: "Дай ГОТОВОЕ РЕШЕНИЕ с кодом на Java..."
↓
Ответ: [Готовый код сортировки на Java с O(n)]
```

### Вопрос 2 (теория):
```
"Что такое полиморфизм?"
↓
Профиль: THEORY  
Промпт: "Краткое объяснение с примерами..."
↓
Ответ: [Теоретическое объяснение с примером на Java]
```

### Вопрос 3 (system design):
```
"Спроектируй систему для обработки 1M запросов в секунду"
↓
Профиль: SYSTEM_DESIGN
↓
Ответ: [Архитектура с компонентами, технологиями, решениями]
```

## 📝 Примеры конфигураций

### Для Java разработчика:

```yaml
interview:
  default_profile: "algorithms"
  programming_language: "Java"
  auto_detect_language: true
```

**Результат:**
- Все решения на Java
- Если вопрос упоминает другой язык - автопереключение
- Автоматическое определение типа задачи

---

### Для C++ разработчика:

```yaml
interview:
  default_profile: "algorithms"
  programming_language: "C++"
  auto_detect_language: true
```

**Результат:**
- Все решения на C++
- STL контейнеры, указатели, etc.

---

### Для Full-stack разработчика:

```yaml
interview:
  default_profile: "backend"
  programming_language: "JavaScript"  # или TypeScript
  auto_detect_language: true
```

**Результат:**
- Backend код на JS/Node.js
- Frontend автоопределится если вопрос про React

## 🔄 Переключение языка на лету

Если вопрос явно указывает другой язык - Hintsage автоматически переключится!

**Пример:**
```yaml
# В config.yaml: programming_language: "Java"
```

**Диалог:**
```
Вопрос 1: "Реализуй quicksort"
→ Ответ на Java (по умолчанию)

Вопрос 2: "А теперь то же самое на Python"
→ Ответ на Python (автоопределение!)

Вопрос 3: "Как это в C++ сделать?"
→ Ответ на C++ (автоопределение!)
```

## 🎨 Кастомизация промптов

Можете настроить свой промпт для любого профиля:

```python
# В коде или через API (будущая фича)
prompt_manager.set_custom_prompt(
    InterviewProfile.ALGORITHMS,
    """Ты - эксперт по Java и алгоритмам.
    
    Всегда давай решения с использованием:
    - Collections framework
    - Stream API где уместно
    - Generics
    
    Код должен быть production-ready."""
)
```
