### **✅ ИСПРАВЛЕНИЕ #4: Runtime проверка доступа к моделям**

**Добавлено:**
```python
# modules/models/model_manager.py

def can_use_model(self, model_name: str, tier: str) -> bool:
    """Проверить может ли тариф использовать модель"""
    model_info = self.registry.get("models", {}).get(model_name, {})
    model_tier = model_info.get("tier", "free").lower()
    
    # Иерархия тарифов
    tier_hierarchy = {
        "free": ["free"],
        "pro": ["free", "pro"],
        "enterprise": ["free", "pro", "enterprise"]
    }
    
    allowed_tiers = tier_hierarchy.get(tier.lower(), ["free"])
    can_use = model_tier in allowed_tiers
    
    if not can_use:
        logger.warning(f"⚠️ [SECURITY] Тариф '{tier}' не может использовать '{model_name}'")
    
    return can_use
```

**Использование:**
```python
# Можно добавить в STTManager:
if engine == "whisper":
    if not model_manager.can_use_model("whisper-small", current_tier):
        raise PermissionError("Whisper доступен только на PRO+")
```

**Результат:**
- ✅ Даже если модель загружена вручную - проверка тарифа
- ✅ Runtime валидация доступа
- ✅ Логирование попыток обхода
