## 🎯 Что такое Hintsage?

**Hintsage** — это умный AI-ассистент для прохождения технических интервью. Приложение в реальном времени:
- 🎤 **Распознает речь** интервьюера
- 📸 **Захватывает скриншоты** вопросов
- 🤖 **Генерирует ответы** с помощью GPT-4
- 💬 **Отображает подсказки** в удобном overlay

---

## 📥 Установка

### Системные требования:
- **ОС:** Windows 10/11 (64-bit)
- **RAM:** Минимум 4GB (8GB рекомендуется)
- **GPU:** NVIDIA GTX 1060+ для PRO тарифа (опционально)
- **Интернет:** Стабильное соединение

### Шаги установки:

1. **Скачайте приложение**
   - Зайдите на [smartsobes.ru](http://smartsobes.ru)
   - Войдите в личный кабинет
   - Скачайте `Hintsage.exe`

2. **Запустите приложение**
   - Распакуйте архив в удобную папку
   - Запустите `Hintsage.exe`
   - При первом запуске Windows может показать предупреждение — нажмите "Подробнее" → "Выполнить в любом случае"

3. **Первый запуск**
   - Приложение запустится с FREE тарифом
   - Overlay окно появится в правом верхнем углу экрана
   - Статус: "Готов к работе" (зеленый)

## 🚀 Быстрый старт

### Базовый сценарий использования:

1. **Запустите Hintsage.exe**
   - Overlay окно появится автоматически

2. **Начните интервью**
   - Дождитесь вопроса от интервьюера

3. **Нажмите горячую клавишу**
   - `Ctrl + Shift + Q` — захват аудио вопроса
   - `Ctrl + Shift + S` — скриншот экрана с вопросом

4. **Получите ответ**
   - Приложение распознает вопрос
   - GPT-4 сгенерирует ответ
   - Ответ отобразится в overlay окне

5. **Используйте подсказку**
   - Прочитайте ответ
   - Сформулируйте свой ответ на основе подсказки
   - Продолжайте интервью

## ⌨️ Горячие клавиши

| Комбинация | Действие |
|------------|----------|
| `Ctrl + Shift + Q` | **Захват аудио вопроса** - начать запись |
| `Ctrl + Shift + S` | **Скриншот экрана** - захватить текст вопроса |
| `Ctrl + Shift + M` | **Ручной триггер** - обработать текущий вопрос |
| `Ctrl + Shift + C` | **Очистить контекст** - сбросить историю |
| `Ctrl + Shift + L` | **Авторизация** - открыть страницу входа |

**Совет:** Используйте `Ctrl + Shift + Q` для голосовых интервью и `Ctrl + Shift + S` для текстовых вопросов на экране.

## 💡 Советы по использованию

### Для лучшего качества распознавания:

1. **Используйте хороший микрофон**
   - Встроенный микрофон ноутбука может давать плохое качество
   - Рекомендуется внешний микрофон или гарнитура

2. **Минимизируйте фоновый шум**
   - Закройте окна
   - Выключите вентиляторы
   - Используйте тихое помещение

3. **Говорите четко**
   - Не спешите
   - Делайте паузы между словами
   - Избегайте слов-паразитов

### Для эффективного использования контекста:

1. **Следите за индикатором контекста**
   - Когда контекст близок к лимиту (красный), очистите его

2. **Используйте `Ctrl + Shift + C`**
   - Очищайте контекст перед новой темой
   - Это улучшит качество ответов

3. **Не перегружайте контекст**
   - Один контекст = одна тема/раздел интервью
   - Новая тема = новый контекст

### Для безопасности:

1. **Overlay окно защищено от скриншотов**
   - Windows не сможет захватить окно
   - Zoom/Teams/Skype не увидят overlay

2. **Не показывайте overlay в камеру**
   - Overlay не виден на захватах экрана
   - Но виден в физическую камеру

3. **Используйте два монитора**
   - Overlay на втором мониторе
   - Камера на первый монитор
   - Интервьюер не увидит overlay

## 🔧 Настройка

### Изменение позиции overlay:

1. Откройте `config.yaml` в папке приложения
2. Найдите секцию `ui.overlay`
3. Измените `position`:
   - `"top-left"` — верхний левый угол
   - `"top-right"` — верхний правый угол (по умолчанию)
   - `"bottom-left"` — нижний левый угол
   - `"bottom-right"` — нижний правый угол

### Изменение размера overlay:

```yaml
ui:
  overlay:
    width: 400    # Ширина в пикселях
    height: 600   # Высота в пикселях
```

### Изменение прозрачности:

```yaml
ui:
  overlay:
    opacity: 0.95  # От 0.0 (прозрачный) до 1.0 (непрозрачный)
```

### Настройка аудио:

```yaml
audio:
  source: "both"  # "microphone" | "loopback" | "both"
  sample_rate: 16000
  channels: 1
  chunk_duration: 1
```

## 🆘 Решение проблем

Если возникли проблемы, см. подробное руководство:
- 📋 [FAQ.md](./FAQ.md) - Частые вопросы
- 🔧 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) - Решение проблем

### Быстрые решения:

**Приложение не запускается:**
- Проверьте, что у вас Windows 10/11
- Запустите от имени администратора
- Проверьте антивирус (добавьте в исключения)

**Не работает распознавание речи:**
- Проверьте микрофон в настройках Windows
- Убедитесь, что микрофон не занят другим приложением
- Попробуйте изменить `audio.source` в config.yaml

**Не генерируются ответы:**
- Проверьте интернет-соединение
- Убедитесь, что используете VPN (если в России)
- Проверьте лог файл на наличие ошибок API

**Overlay не отображается:**
- Проверьте, что приложение запущено
- Попробуйте изменить позицию overlay
- Перезапустите приложение
