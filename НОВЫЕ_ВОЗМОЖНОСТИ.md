# 🎉 Новые возможности Hintsage

## ✨ Что добавлено:

### 1️⃣ **Накопительный режим ответов** [ПАМЯТЬ + СЛОВО]

**До:** Каждый новый ответ стирал предыдущий  
**Теперь:** Ответы накапливаются с разделителями

**Пример:**
```
[Q1] Что такое ArrayList?

💡 ArrayList - динамический массив...

────────────────────────────────────────────────────────

[Q2] А LinkedList?

💡 LinkedList - двусвязный список...

────────────────────────────────────────────────────────

[Q3] В чем разница?

💡 Разница в производительности операций...
```

**Настройка** в `config.yaml`:
```yaml
ui:
  accumulate_answers: true  # false - вернуть старый режим
```

---

### 2️⃣ **Контекст диалога** [ПАМЯТЬ + МЫСЛЕТЕ]

**Модель ПОМНИТ предыдущие вопросы и ответы!**

**Как работает:**
- 📝 История последних **10 сообщений** (5 пар вопрос-ответ)
- 🔄 При смене профиля сохраняет **6 последних сообщений**
- 💾 Автоматически сохраняет в `data/sessions/`

**Визуальный индикатор:**
```
📝 Контекст: 8  ← Показывает количество сообщений
```

**Цвета:**
- 🟢 Зеленый (< 10) - норма
- 🟠 Оранжевый (10-20) - много контекста
- 🔴 Красный (> 20) - близко к лимиту

**Пример использования:**
```
[Вы] Что такое стек?
[AI] Стек - структура данных LIFO...

[Вы] А можешь показать код?  ← AI помнит что речь о стеке!
[AI] Конечно! Вот реализация стека:
     class Stack:...

[Вы] Как это применить на практике?  ← AI помнит весь диалог!
[AI] Используя стек из предыдущего примера...
```

**Очистка контекста:**
- `Ctrl+Shift+C` - очистить память (начать с чистого листа)

---

### 3️⃣ **Улучшенный контекст между профилями**

**До:** При смене профиля (theory → algorithms) терялся контекст  
**Теперь:** Сохраняет 6 последних сообщений для связности

**Пример:**
```
Q: Что такое полиморфизм?  (theory)
A: ...

Q: Покажи пример на Java  (algorithms) ← Помнит про полиморфизм!
A: Вот пример полиморфизма...
```

---

### 4️⃣ **Запуск без консоли** [ШТОР + ПУТЬ]

**3 новых способа запуска:**

| Файл | Консоль | Рекомендуется |
|------|---------|---------------|
| `start_hidden.bat` | Скрывается | ⭐ Для интервью |
| `start_background.bat` | Минимизируется | Обычное использование |
| `start_silent.vbs` | Скрыта полностью | Полная невидимость |

**Как использовать:**
```
Двойной клик → start_hidden.bat
Консоль покажет инфо и закроется
Приложение продолжит работу!
```

## 🎯 **Как это использовать на интервью:**

### **Сценарий 1: Связанные вопросы**
```
1. "Расскажи про HashMap"
   → Получаете ответ
   
2. "А что насчет коллизий?"  ← Модель помнит про HashMap!
   → Ответ в контексте предыдущего
   
3. "Покажи код"  ← Помнит и про HashMap, и про коллизии!
   → Код с учетом всего обсуждения
```

### **Сценарий 2: Уточнения**
```
1. "Реализуй quicksort"
   → Получаете базовую реализацию
   
2. "А можно оптимизировать?"  ← Помнит код из п.1!
   → Оптимизированная версия
   
3. "Добавь комментарии"  ← Помнит весь контекст!
   → Код с комментариями
```

### **Сценарий 3: Накопление информации**
Все ответы видны одновременно - можно:
- 📜 Пролистывать вверх к предыдущим
- 🔍 Сравнивать ответы
- 📝 Видеть всю историю диалога

---

## ⚙️ **Настройки:**

### **Включить/выключить накопление:**

`config.yaml`:
```yaml
ui:
  accumulate_answers: true   # true = накопление, false = перезапись
```

### **Размер контекста:**

`config.yaml`:
```yaml
context:
  max_messages: 20           # Максимум сообщений в памяти
  context_window: 4000       # Максимум токенов
```

---

## 🔧 **Управление контекстом:**

| Действие | Клавиша | Эффект |
|----------|---------|--------|
| Очистить контекст | `Ctrl+Shift+C` | Стирает память + display |
| Очистить только display | Кнопка **[CLEAR]** | Только экран (контекст остается) |

## 📊 **Технические детали:**

### **Архетипы:**
- **[ПАМЯТЬ]** - ContextManager хранит историю
- **[СЛОВО + ЛИЧЬ]** - UI отображает накопительно
- **[МЫСЛЕТЕ]** - LLM использует контекст для связности

### **Файлы сессий:**
```
data/sessions/
  └── session_20251009_214445.json  ← Автосохранение
```
