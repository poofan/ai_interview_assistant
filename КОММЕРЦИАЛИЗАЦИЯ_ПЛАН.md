## 🎯 **ЭТАП 2: АВТОРИЗАЦИЯ (следующий шаг)**

### **Модули для создания:**

```
modules/auth/
├─ __init__.py
├─ auth_manager.py       ← JWT проверка, хранение токенов
├─ login_dialog.py       ← PyQt6 форма входа
├─ feature_manager.py    ← Управление доступом к фичам
└─ token_refresher.py    ← Автообновление токенов (фоновое)
```

### **Интеграция в main.py:**

```python
from modules.auth import AuthManager, LoginDialog, FeatureManager

def main():
    qt_app = QApplication(sys.argv)
    
    # 1. Проверка авторизации
    auth_manager = AuthManager()
    if not auth_manager.is_authenticated():
        login_dialog = LoginDialog(auth_manager)
        if login_dialog.exec() != QDialog.DialogCode.Accepted:
            return  # Отмена входа
    
    # 2. Загрузка features
    feature_manager = FeatureManager(auth_manager.get_features())
    
    # 3. Запуск с ограничениями
    app = HintsageApp(qt_app, feature_manager)
    app.start()
```

**Время:** 1-2 дня

## 🎟️ **ЭТАП 3: BACKEND API**

### **Технологии:**
- FastAPI (Python)
- PostgreSQL
- JWT (RS256)
- Stripe webhooks

### **Endpoints:**

```python
POST /auth/register
  Input:  {email, password}
  Output: {success: true}

POST /auth/login
  Input:  {email, password}
  Output: {access_token, refresh_token, features}

POST /auth/refresh
  Input:  {refresh_token}
  Output: {access_token}

GET /auth/verify
  Input:  Authorization: Bearer <token>
  Output: {valid: true, features: {...}}

POST /webhooks/stripe
  Input:  Stripe webhook events
  Output: {received: true}
```

**Время:** 3-5 дней
