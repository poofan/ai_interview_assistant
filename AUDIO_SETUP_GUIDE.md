# 🎤 Настройка аудио для захвата собеседника

## Проблема
По умолчанию приложение захватывает только ваш микрофон, но не голос собеседника из динамиков/наушников.

## Решение 1: Включить Stereo Mix (Рекомендуется)

### Шаги:
1. **Правый клик** на иконку звука в системном трее
2. Выберите **"Открыть параметры звука"**
3. Нажмите **"Панель управления звуком"** (справа)
4. Перейдите на вкладку **"Запись"**
5. **Правый клик** в пустом месте → **"Показать отключенные устройства"**
6. **Правый клик** на **"Stereo Mix"** → **"Включить"**
7. **Правый клик** на **"Stereo Mix"** → **"Сделать устройством по умолчанию"**

### Проверка:
- В списке устройств записи должен появиться **"Stereo Mix"**
- Устройство должно быть **активным** (не серым)

## Решение 2: Виртуальный аудио драйвер

### VB-Cable (Бесплатно):
1. Скачайте с https://vb-audio.com/Cable/
2. Установите **VB-Cable**
3. В настройках звука Windows:
   - **Воспроизведение**: выберите **"CABLE Input"**
   - **Запись**: выберите **"CABLE Output"**

### VoiceMeeter (Бесплатно):
1. Скачайте с https://vb-audio.com/Voicemeeter/
2. Установите **VoiceMeeter**
3. Настройте маршрутизацию аудио в интерфейсе VoiceMeeter

## Проверка работы

После настройки:
1. Запустите Hintsage
2. В логах должно быть: `[BOTH] Найдено loopback устройство: Stereo Mix`
3. Вместо: `[BOTH] Используется микрофон (loopback недоступен)`

## Альтернатива: Только микрофон

Если не получается настроить системный захват:
- Приложение будет работать только с вашим микрофоном
- Собеседника слышно не будет
- Но все остальные функции (OCR, AI) работают

## Устранение проблем

### "Device unavailable":
- Перезапустите приложение
- Проверьте, что Stereo Mix включен
- Попробуйте запустить от имени администратора

### "Stereo Mix не найден":
- Убедитесь, что драйвер звуковой карты поддерживает Stereo Mix
- Попробуйте обновить драйверы звука
- Используйте виртуальный аудио драйвер

---

**Примечание:** Настройка системного аудио может потребовать перезапуска приложения.
