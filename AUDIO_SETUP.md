# 🎤 Настройка захвата аудио Hintsage

## Важно понять источники аудио!

### 🎯 Для собеседований нужно захватывать голос СОБЕСЕДНИКА:

```yaml
audio:
  source: "system"  # ← Захват с динамиков/наушников
```

**Почему "system", а не "microphone"?**

| Источник | Что захватывается | Когда использовать |
|----------|-------------------|-------------------|
| `microphone` | ВАШ голос | ❌ Не подходит для собеседований |
| `system` | Голос СОБЕСЕДНИКА через динамики/наушники | ✅ **Правильно для собеседований!** |
| `both` | Весь диалог (оба источника) | ⚡ Идеально, но требует доработки |

## 🔧 Настройка "Stereo Mix" в Windows

Для захвата системного аудио нужно включить **"Stereo Mix"** (или "Микшер стерео"):

### Шаг 1: Открыть настройки звука

1. **ПКМ на значке звука** в трее → "Звуки"
2. Или: `Пуск` → `Параметры` → `Система` → `Звук`

### Шаг 2: Включить "Stereo Mix"

1. Перейдите на вкладку **"Запись"**
2. **ПКМ в пустой области** → **"Показать отключенные устройства"**
3. Найдите **"Stereo Mix"** или **"Микшер стерео"**
4. **ПКМ на Stereo Mix** → **"Включить"**
5. **ПКМ на Stereo Mix** → **"Использовать по умолчанию"**

### Шаг 3: Проверка

```bash
# В Python:
from modules.audio_capture import AudioCapture
ac = AudioCapture(source="system")
ac.list_devices()
```

Должны увидеть устройство с названием типа:
- "Stereo Mix"
- "Микшер стерео"  
- "What U Hear"
- "Wave Out Mix"

## ⚠️ Если "Stereo Mix" недоступен:

### Вариант 1: Используйте виртуальный аудиокабель

**VB-Audio Virtual Cable** (бесплатно):
1. Скачать: https://vb-audio.com/Cable/
2. Установить
3. В настройках Zoom/Teams/Meet:
   - Динамики → "CABLE Input"
4. В настройках Windows:
   - Запись → "CABLE Output" → По умолчанию
5. В Hintsage:
   ```yaml
   audio:
     source: "system"  # Будет захватывать через CABLE
   ```

### Вариант 2: Программный микшер (Voicemeeter)

**Voicemeeter** (бесплатно):
1. Скачать: https://vb-audio.com/Voicemeeter/
2. Настроить маршрутизацию аудио
3. Захватывать виртуальный вход

### Вариант 3: Только ручной режим

Если не получается настроить системное аудио:
```yaml
audio:
  source: "microphone"  # Ваш голос (ручной режим)

question_detector:
  mode: "manual"  # Только ручной триггер
```

**Как использовать:**
1. Собеседник задает вопрос
2. Вы **повторяете** вопрос в микрофон шепотом/про себя
3. Нажимаете `Ctrl+Shift+Q`
4. Получаете ответ

## 🎯 Рекомендуемая конфигурация для собеседований:

```yaml
audio:
  source: "system"  # Голос собеседника через динамики
  sample_rate: 16000
  channels: 1  # Моно (достаточно)
  chunk_size: 1024
  buffer_seconds: 30  # Храним последние 30 сек
```

**Преимущества:**
- ✅ Автоматический захват вопросов собеседника
- ✅ Не нужно ничего повторять
- ✅ Незаметно для собеседника
- ✅ Работает в наушниках

---

## 🎧 Важно про наушники!

### ✅ Правильная схема:

```
Собеседник (Zoom/Teams)
    ↓
Динамики/Наушники → [Stereo Mix] → Hintsage STT → LLM → Ответ
    ↓
Ваши уши слышат вопрос
```

### ❌ Неправильная схема:

```
Ваш микрофон → Hintsage STT (ваш голос, не вопросы!)
```

## 🔧 Диагностика - какое устройство используется:

Добавьте в начало `main.py` для проверки:

```python
# Перед запуском
self.audio_capture.list_devices()
```

Вы увидите все доступные устройства и какое выбрано.
