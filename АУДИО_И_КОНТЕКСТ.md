# 🎙️ Улучшения аудио и контекста

## ✅ **Исправлено:**

### 1️⃣ **Обрезание ответов агента** [СЛОВО + МЫСЛЕТЕ]

**Проблема:** `max_tokens: 500` - слишком мало  
**Решение:** Увеличено до `2000` токенов

```yaml
llm:
  max_tokens: 2000  # Было 500
  context_window: 6000  # Было 4000
```

**Результат:** Полные ответы без обрезания!

---

### 2️⃣ **Двойной аудиопоток** [ВЕДИ + ЧЕЛО]

**Проблема:** Слышен только один источник (собеседник ИЛИ вы)  
**Решение:** Новый режим `both`

```yaml
audio:
  source: "both"  # Новый режим!
```

**Как работает:**
1. 🔍 Ищет "Stereo Mix" / "What U Hear" (системный звук)
2. ✅ Если найден → захватывает голос собеседника
3. ❌ Если не найден → захватывает ваш микрофон
4. 📝 Логирует что именно используется

---

## 🎯 **Практическое применение:**

### **Сценарий: Плохо слышно собеседника**

**До:**
```
[Собеседник] "Что такое... хм... [неразборчиво]... структура?"
[Вы] Ctrl+Shift+Q → AI не понимает контекст
```

**Теперь:**
```
[Собеседник] "Что такое... хм... [неразборчиво]... структура?"
[Вы] "Речь шла про HashMap" → Ctrl+Shift+Q
[AI] Помнит что обсуждались структуры данных!
```

### **Режимы аудио:**

| Режим | Захватывает | Использование |
|-------|-------------|---------------|
| `microphone` | Только ваш голос | Когда вы хотите задать вопрос |
| `system` | Только собеседник | Когда нужно только слушать |
| **`both`** | **Оба источника** | **Универсальный режим** ⭐ |

## 🔧 **Настройка Stereo Mix (Windows):**

### **Включить Stereo Mix:**

1. **Правый клик** на иконку звука → "Открыть параметры звука"
2. **"Панель управления звуком"** → вкладка "Запись"
3. **Правый клик** в пустом месте → "Показать отключенные устройства"
4. **Правый клик** на "Stereo Mix" → "Включить"
5. **Правый клик** на "Stereo Mix" → "Сделать устройством по умолчанию"

### **Альтернативы:**
- **Realtek:** "What U Hear"
- **Creative:** "Stereo Mix"
- **ASUS:** "Stereo Mix"
