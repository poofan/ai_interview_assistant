# 📦 Система Версионирования Hintsage

## 🎯 Архитектура

Hintsage использует **семантическое версионирование** (`MAJOR.MINOR.PATCH`) с проверкой обновлений через backend API.

---

## 📋 Компоненты Системы

### 1. **VersionManager** (`modules/config/version_manager.py`)
- **Роль:** Управление версиями и проверка обновлений
- **Архетипы:** АЗ (управление доступом) + ШТОР (безопасность)
- **Функции:**
  - Хранение текущей версии приложения
  - Проверка наличия обновлений через API
  - Сравнение версий (semantic versioning)
  - Определение критических обновлений
  - Кэширование результатов проверки

### 2. **UpdateDialog** (`modules/ui/update_dialog.py`)
- **Роль:** GUI для уведомлений об обновлениях
- **Архетипы:** АЗ + ДОБРО
- **Функции:**
  - Отображение информации о новой версии
  - Показ changelog
  - Кнопки действий: "Скачать", "Позже", "Пропустить"
  - Специальная обработка критических обновлений

## 🚀 API Endpoint (Backend)

### **POST** `/version/check`

**Request:**
```json
{
  "current_version": "1.0.0",
  "platform": "windows",
  "timestamp": "2025-10-12T18:00:00Z"
}
```

**Response (Обновление доступно):**
```json
{
  "latest_version": "1.1.0",
  "release_date": "2025-10-15",
  "download_url": "https://hintsage.com/download/Hintsage-1.1.0.exe",
  "changelog": [
    "✨ Добавлена поддержка Python-кода",
    "🐛 Исправлена ошибка с GPU",
    "⚡ Улучшена производительность STT"
  ],
  "critical": false,
  "min_version": "1.0.0"
}
```

**Response (Актуальная версия):**
```json
{
  "latest_version": "1.0.0",
  "up_to_date": true
}
```

**Response (Критическое обновление):**
```json
{
  "latest_version": "1.2.0",
  "critical": true,
  "min_version": "1.2.0",
  "changelog": [
    "🔒 КРИТИЧЕСКОЕ: Исправлена уязвимость безопасности",
    "⚠️ Обновление обязательно для всех пользователей"
  ],
  "download_url": "https://hintsage.com/download/Hintsage-1.2.0.exe"
}
```

## 🔐 Типы Обновлений

### 1. **Обычное Обновление**
- `critical: false`
- Пользователь может выбрать: "Скачать", "Позже", "Пропустить"
- Приложение продолжает работу

### 2. **Критическое Обновление**
- `critical: true`
- Пользователь **обязан** скачать обновление
- Кнопки "Позже" и "Пропустить" **скрыты**
- Если пользователь закрывает диалог без скачивания → **приложение завершается**

### 3. **Offline Режим**
- Если backend недоступен → приложение работает без проверки обновлений
- Логируется предупреждение: `⚠️ Сервер обновлений недоступен`

## 📝 Изменение Версии

### **В коде** (`modules/config/version_manager.py`):
```python
class VersionManager:
    # Текущая версия приложения (встроенная)
    CURRENT_VERSION = "1.0.0"  # ← ИЗМЕНИТЬ ЗДЕСЬ
```

### **При сборке .exe**:
1. Обновите `CURRENT_VERSION` в `version_manager.py`
2. Соберите новый `.exe` через `build.bat`
3. Загрузите `.exe` на сервер
4. Обновите backend API с новой версией
