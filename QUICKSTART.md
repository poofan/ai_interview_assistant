# ⚡ Быстрый старт Hintsage

## 5-минутная установка

### 1. Установка зависимостей (2 минуты)

```bash
# Активируйте виртуальное окружение
venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Загрузка модели Vosk (2 минуты)

```bash
# Скачайте и распакуйте:
# https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

# Результат:
# models/vosk-model-small-ru-0.22/
```

### 3. Настройка (1 минута)

```bash
# Скопируйте конфиг
copy config.example.yaml config.yaml

# Откройте и добавьте OpenAI API ключ
notepad config.yaml
```

Измените только это:
```yaml
openai:
  api_key: "sk-ваш-ключ-OpenAI"
```

Получить ключ: https://platform.openai.com/api-keys

### 4. Запуск!

**Вариант A: Через скрипт (проще всего)** 🚀
```bash
# Двойной клик на:
start.bat              # С подробной информацией
# ИЛИ
start_quick.bat        # Быстрый запуск без пауз
```

**Вариант B: Создать ярлык на рабочем столе** 🖥️
```bash
# Правый клик -> Запуск от имени администратора:
create_shortcut.ps1
```

**Вариант C: Через командную строку**
```bash
venv\Scripts\python.exe main.py
```

## Первое использование

### Тестовый сценарий:

1. **Запустите приложение** - появится overlay окно
2. **Говорите в микрофон**: "Что такое binary search?"
3. **Дождитесь распознавания** (в логах появится текст)
4. **Получите ответ** в overlay окне!

### Ручной режим:

Если автоматическая детекция не срабатывает:

1. Задайте вопрос вслух
2. Нажмите `Ctrl+Shift+Q` (или кнопку "Триггер")
3. Получите ответ

### Работа со скриншотами:

1. Откройте код/задачу на другом мониторе
2. Нажмите `Ctrl+Shift+S`
3. Приложение распознает текст и даст объяснение

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+Shift+Q` | Ручной триггер вопроса |
| `Ctrl+Shift+S` | Скриншот + OCR |
| `Ctrl+Shift+C` | Очистить контекст |
| `Esc` | Скрыть/показать окно |
| `Ctrl+Q` | Выход |

## Настройка под себя

### Изменить модель GPT:

```yaml
openai:
  model: "gpt-4o-mini"  # Дешевле и быстрее
  # model: "gpt-4"      # Точнее, но дороже
```

### Изменить системный промпт:

```yaml
openai:
  system_prompt: "Ты - эксперт по Python и алгоритмам. Отвечай кратко и с примерами кода."
```

### Позиция окна:

```yaml
ui:
  overlay:
    position: "top-right"  # или top-left, bottom-left, bottom-right
    opacity: 0.95          # 0-1
```

### Режим детекции вопросов:

```yaml
question_detector:
  mode: "auto"     # Автоматическая детекция (regex)
  # mode: "manual" # Только ручной триггер
  # mode: "hybrid" # Regex + ML (медленнее, точнее)
```

## Советы и трюки

### 1. Для лучшего распознавания:
- Говорите четко и не очень быстро
- Используйте качественный микрофон
- Минимизируйте фоновый шум

### 2. Для экономии токенов:
```yaml
openai:
  max_tokens: 300  # Короткие ответы
  
context:
  max_messages: 10  # Меньше контекста
```

### 3. Для невидимости:
```yaml
security:
  anti_screenshot: true
  anti_screen_share: true
  
ui:
  overlay:
    phantom_mode: true  # Мышь проходит сквозь окно
```

### 4. Добавьте свои вопросительные паттерны:
```yaml
question_detector:
  patterns:
    - "расскажи"
    - "объясни"
    - "как работает"
    - "в чем разница"
```

## Частые вопросы

### Q: Не распознается русская речь
**A:** Убедитесь, что скачали русскую модель Vosk и указали правильный путь в `config.yaml`

### Q: Overlay не появляется
**A:** Проверьте логи в `logs/hintsage.log`. Возможно, ошибка инициализации.

### Q: OpenAI возвращает ошибку
**A:** Проверьте:
- Правильность API ключа
- Наличие кредитов на аккаунте
- Доступность модели (gpt-4o может требовать специального доступа)

### Q: Микрофон не работает
**A:** Запустите `audio_capture.list_devices()` и выберите правильное устройство

### Q: Медленно работает
**A:** 
- Используйте `vosk` вместо `whisper`
- Уменьшите модель GPT до `gpt-4o-mini`
- Отключите ML детекцию: `mode: "regex"`

## Безопасность на собеседовании

⚠️ **ВАЖНО:**
