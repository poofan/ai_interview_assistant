## ❌ **УЯЗВИМОСТЬ #1: Config.yaml доступен пользователю**

### **Описание:**
`config.yaml` включен в .exe и может быть извлечен/изменен пользователем.

### **Код:**
```python
# hintsage.spec, строка 25
datas += [
    ('config.example.yaml', '.'),
    ('config.yaml', '.'),  # ❌ УЯЗВИМОСТЬ!
]
```

### **Эксплуатация:**
```
1. FREE пользователь распаковывает .exe (через 7-Zip или PyInstaller Extractor)
2. Находит config.yaml в извлеченных файлах
3. Меняет:
   stt:
     default_engine: "whisper"  # Было "vosk"
4. Пересобирает .exe или запускает с измененным конфигом
5. Получает PRO функцию бесплатно!
```

### **Риск:**
- 🔴 **КРИТИЧЕСКИЙ**
- FREE пользователи получают PRO функции
- Потеря прибыли
- Подрыв бизнес-модели

## ❌ **УЯЗВИМОСТЬ #2: Нет проверки тарифа при выборе STT движка**

### **Описание:**
STT движок выбирается из config.yaml, а не из Feature Manager.

### **Код:**
```python
# main.py, строка 213-216
self.stt_manager = STTManager(
    default_engine=self.config.get("stt.default_engine", "vosk"),  # ❌ Из конфига!
    config=stt_config
)

# ✅ Должно быть:
allowed_engine = self.feature_manager.get_stt_engine()  # Из тарифа!
self.stt_manager = STTManager(
    default_engine=allowed_engine,
    config=stt_config
)
```

### **Эксплуатация:**
```yaml
# config.yaml
stt:
  default_engine: "whisper"  # FREE пользователь меняет на whisper
```

### **Риск:**
- 🔴 **КРИТИЧЕСКИЙ**
- FREE пользователи используют PRO движок
- Если модель уже загружена - работает без оплаты

## ❌ **УЯЗВИМОСТЬ #4: Модели могут быть загружены вручную**

### **Описание:**
Model Manager проверяет только наличие файлов, но не тариф при использовании.

### **Код:**
```python
# modules/models/model_manager.py
def check_model_exists(self, model_name: str) -> bool:
    model_path = self.models_dir / model_name
    return model_path.exists()  # ❌ Только файловая проверка!
```

### **Эксплуатация:**
```
1. FREE пользователь скачивает Whisper модель с Hugging Face
2. Кладет в models/whisper-small/
3. Меняет config.yaml: default_engine: "whisper"
4. Получает PRO функцию бесплатно!
```

### **Риск:**
- 🟡 **ВЫСОКИЙ**
- Технически подкованные пользователи могут обойти оплату
- Требуется знание как скачать модели

### **РЕШЕНИЕ 4: Runtime проверка доступа к моделям**

```python
# modules/models/model_manager.py

def can_use_model(self, model_name: str, tier: str) -> bool:
    """
    Проверить может ли тариф использовать модель
    
    Args:
        model_name: Название модели
        tier: Текущий тариф пользователя
    
    Returns:
        True если тариф позволяет использовать модель
    """
    model_info = self.registry.get("models", {}).get(model_name, {})
    model_tier = model_info.get("tier", "free")
    
    # Проверка иерархии тарифов
    tier_hierarchy = {
        "free": ["free"],
        "pro": ["free", "pro"],
        "enterprise": ["free", "pro", "enterprise"]
    }
    
    allowed_tiers = tier_hierarchy.get(tier.lower(), ["free"])
    return model_tier in allowed_tiers

# Использование в STTManager:
if model_name == "whisper" and not model_manager.can_use_model("whisper-small", current_tier):
    raise PermissionError(f"Whisper доступен только на PRO+ тарифе. Ваш тариф: {current_tier}")
```
