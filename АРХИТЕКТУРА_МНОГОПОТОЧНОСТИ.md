## 🎯 **Компоненты решения:**

### 1️⃣ **RequestQueue (Очередь запросов)**

**Архетип:** [ДОБРО + ИЖЕ] - хранение и поток запросов

**⚡ ВАЖНО:** Используем **Completion Order**, а не FIFO для отображения!

```python
class RequestQueue:
    """
    Очередь для параллельной обработки запросов
    
    ЗАПУСК: Параллельный (до max_workers одновременно)
    ОТОБРАЖЕНИЕ: По мере готовности (Completion Order)
    КОНТЕКСТ: В порядке запроса (сохраняем FIFO для истории)
    """
    def __init__(self, max_workers: int = 3):
        self.active_requests = {}  # {request_id: RequestTask}
        self.request_order = []  # Порядок запросов для нумерации
        self.max_workers = max_workers
        self.thread_pool = QThreadPool.globalInstance()
        self.thread_pool.setMaxThreadCount(max_workers)
        self.next_number = 1  # Для нумерации [Q1], [Q2], [Q3]...
    
    def submit(self, audio_buffer, request_type="manual") -> str:
        """Добавить запрос в обработку (запустить СРАЗУ)"""
        request_id = f"req_{int(time.time() * 1000)}"
        request_number = self.next_number
        self.next_number += 1
        
        task = RequestTask(
            request_id, 
            request_number,  # Для UI: [Q1], [Q2]...
            audio_buffer, 
            request_type
        )
        
        # Сигналы для обновления UI
        task.signals.started.connect(self._on_started)
        task.signals.progress.connect(self._on_progress)
        task.signals.finished.connect(self._on_finished)  # ← СРАЗУ отобразить!
        task.signals.error.connect(self._on_error)
        
        # Запускаем СРАЗУ (если есть свободный worker)
        self.thread_pool.start(task)
        self.active_requests[request_id] = task
        self.request_order.append(request_id)
        
        return request_id
```

**Преимущества:**
- ✅ **Completion Order** - показываем как только готово
- ✅ **Параллельный запуск** - до max_workers одновременно
- ✅ **Сохранение порядка** - для контекста и нумерации
- ✅ **Лимит ресурсов** - не перегружаем GPU

---

### 📊 **Сравнение подходов:**

| Критерий | FIFO отображение | ✅ Completion Order |
|----------|------------------|---------------------|
| **Скорость ответа** | ❌ Ждет предыдущие | ✅ Показывает сразу |
| **UX при интервью** | ❌ Фрустрация | ✅ Мгновенная реакция |
| **Порядок в UI** | ✅ Последовательный | ⚠️ Может нарушаться |
| **Порядок в контексте** | ✅ Сохранен | ✅ Сохранен через номера |
| **Сложность реализации** | 🟢 Простая | 🟡 Средняя |

**Вывод:** Completion Order лучше для интервью!

### 🔄 **Альтернатива: Hybrid подход (опционально)**

Если хотите **строгий порядок отображения** + параллельную обработку:

```python
class HybridDisplayQueue:
    """
    Обрабатывает параллельно, но отображает по порядку
    """
    def __init__(self):
        self.pending_answers = {}  # {request_number: answer}
        self.next_to_display = 1
    
    def on_answer_ready(self, request_number, answer):
        """Ответ готов"""
        self.pending_answers[request_number] = answer
        
        # Отображаем все готовые по порядку
        while self.next_to_display in self.pending_answers:
            answer = self.pending_answers.pop(self.next_to_display)
            self._display(answer)
            self.next_to_display += 1
```

**Пример:**
```
Q1 готов за 10 сек
Q2 готов за 3 сек
Q3 готов за 5 сек

Completion Order:
  t=3s:  Показать Q2 ✅
  t=5s:  Показать Q3 ✅
  t=10s: Показать Q1 ✅

Hybrid (FIFO display):
  t=3s:  Q2 готов → буфер [Q2]
  t=5s:  Q3 готов → буфер [Q2, Q3]
  t=10s: Q1 готов → показать Q1, Q2, Q3 одновременно ✅
```

**Рекомендация:** Для интервью лучше **Completion Order** (мгновенная реакция важнее порядка)

### ⚠️ **ВАЖНО: Управление контекстом**

При **Completion Order** возникает вопрос: как добавлять в контекст?

**Проблема:**
```python
# Q1 готов за 10 сек → добавляем в контекст
context.add_user_message("Q1")
context.add_assistant_message("A1")

# Q2 готов за 3 сек (РАНЬШЕ Q1!) → добавляем в контекст
context.add_user_message("Q2")  # ← НЕПРАВИЛЬНЫЙ ПОРЯДОК!
context.add_assistant_message("A2")
```

**Решение:**
```python
class RequestTask:
    def __init__(self, request_id, request_number, ...):
        self.request_number = request_number  # Порядок запроса
    
    def on_finished(self, question, answer):
        # Отправляем в main.py с номером
        self.signals.finished.emit(
            self.request_id,
            self.request_number,  # ← Используем для правильного порядка
            question,
            answer
        )

# В main.py:
def _on_request_finished(self, req_id, req_num, question, answer):
    # Добавляем в буфер с номером
    self.answer_buffer[req_num] = (question, answer)
    
    # Добавляем в контекст ВСЕ готовые по порядку
    while self.next_context_number in self.answer_buffer:
        q, a = self.answer_buffer.pop(self.next_context_number)
        self.context_manager.add_user_message(q)
        self.context_manager.add_assistant_message(a)
        self.next_context_number += 1
    
    # Отображаем СРАЗУ (Completion Order для UI)
    self.overlay_window.display_answer(
        f"[Q{req_num}] {question}\n\n💡 {answer}",
        append_mode=True
    )
```

**Итого:**
- ✅ UI показывает ответы **по мере готовности** (быстро)
- ✅ Контекст сохраняет **правильный порядок** (для LLM)
- ✅ Нумерация [Q1], [Q2] помогает ориентироваться

### 2️⃣ **RequestTask (Рабочая задача)**

**Архетип:** [МЫСЛЕТЕ + РЦИ] - обработка запроса

```python
class RequestTask(QRunnable):
    """
    Один запрос: STT → LLM → результат
    Запускается в отдельном потоке
    """
    class Signals(QObject):
        started = pyqtSignal(str)  # request_id
        progress = pyqtSignal(str, str)  # request_id, stage
        finished = pyqtSignal(str, str, str)  # request_id, question, answer
        error = pyqtSignal(str, str)  # request_id, error_msg
    
    def __init__(self, request_id, audio_buffer, request_type):
        super().__init__()
        self.signals = self.Signals()
        self.request_id = request_id
        self.audio_buffer = audio_buffer
        self.request_type = request_type
    
    def run(self):
        """Выполнение в отдельном потоке"""
        try:
            self.signals.started.emit(self.request_id)
            
            # [ВЕДИ] STT
            self.signals.progress.emit(self.request_id, "STT")
            question = self._do_stt(self.audio_buffer)
            
            # [МЫСЛЕТЕ] LLM
            self.signals.progress.emit(self.request_id, "LLM")
            answer = self._do_llm(question)
            
            # [СЛОВО] Результат
            self.signals.finished.emit(self.request_id, question, answer)
            
        except Exception as e:
            self.signals.error.emit(self.request_id, str(e))
```

**Преимущества:**
- ✅ Каждый запрос независим
- ✅ Сигналы для обновления UI (thread-safe)
- ✅ Обработка ошибок для каждого запроса

### 3️⃣ **ParallelAnswerDisplay (Параллельное отображение)**

**Архетип:** [ЛИЧЬ + СЛОВО] - визуализация

```python
class ParallelAnswerDisplay(QWidget):
    """
    Отображение нескольких ответов параллельно
    """
    def __init__(self):
        super().__init__()
        self.pending_requests = {}  # {request_id: RequestWidget}
        self.layout = QVBoxLayout()
    
    def add_pending_request(self, request_id: str, question: str):
        """Добавить запрос в обработке"""
        widget = RequestWidget(request_id, question)
        widget.set_status("🔄 Обработка...")
        
        self.pending_requests[request_id] = widget
        self.layout.addWidget(widget)
    
    def update_progress(self, request_id: str, stage: str):
        """Обновить прогресс"""
        if request_id in self.pending_requests:
            stages = {
                "STT": "🎙️ Распознавание речи...",
                "LLM": "🤖 Генерация ответа...",
            }
            self.pending_requests[request_id].set_status(stages.get(stage, stage))
    
    def show_answer(self, request_id: str, question: str, answer: str):
        """Отобразить готовый ответ"""
        if request_id in self.pending_requests:
            widget = self.pending_requests[request_id]
            widget.set_answer(answer)
            widget.set_status("✅ Готово")
            del self.pending_requests[request_id]
```

### **2. OpenAI API (Rate limits)**
```python
class RateLimiter:
    """
    Контроль частоты запросов к API
    """
    def __init__(self, requests_per_minute: int = 20):
        self.rpm = requests_per_minute
        self.timestamps = []
    
    async def acquire(self):
        """Ждать разрешения на запрос"""
        # Удаляем старые запросы (> 1 минуты назад)
        now = time.time()
        self.timestamps = [t for t in self.timestamps if now - t < 60]
        
        # Если превысили лимит - ждем
        if len(self.timestamps) >= self.rpm:
            wait_time = 60 - (now - self.timestamps[0])
            await asyncio.sleep(wait_time)
        
        self.timestamps.append(now)
```

## 🎯 **Интеграция в main.py:**

```python
class HintsageApp:
    def __init__(self, config_path: str = "config.yaml"):
        # ... existing code ...
        
        # [ДОБРО + ИЖЕ] - Очередь запросов
        self.request_queue = RequestQueue(
            max_workers=self.config.get("parallel.max_workers", 3)
        )
        
        # Подключаем сигналы
        self.request_queue.signals.request_started.connect(
            self._on_request_started
        )
        self.request_queue.signals.request_finished.connect(
            self._on_request_finished
        )
    
    def _manual_trigger(self) -> None:
        """
        [ЧЕЛО + ЖИВЕТЕ] - Ручной триггер (ASYNC версия)
        """
        logger.info("[TRIGGER] Ручной триггер активирован")
        
        # Берем аудио
        audio_buffer = self.audio_capture.get_buffer(seconds=10)
        
        # Валидация
        if audio_buffer is None or len(audio_buffer) == 0:
            self.overlay_window.show_error("Аудиозахват не активен")
            return
        
        # [ДОБРО] - Отправляем в очередь (не блокируем!)
        request_id = self.request_queue.submit(audio_buffer, "manual")
        
        logger.info(f"[QUEUE] Запрос {request_id} добавлен в очередь")
        
        # Сразу готовы к новому триггеру!
    
    def _on_request_finished(self, request_id: str, question: str, answer: str):
        """
        Обработчик завершения запроса
        """
        # Добавляем в контекст
        self.context_manager.add_user_message(question)
        self.context_manager.add_assistant_message(answer)
        
        # Отображаем ответ
        message_count = len(self.context_manager) // 2
        formatted_answer = f"[Q{message_count}] {question}\n\n💡 {answer}"
        
        self.overlay_window.display_answer(formatted_answer, append_mode=True)
        self.overlay_window.update_context_indicator(len(self.context_manager))
```
