# 🔥 HOTKEYS - Справочник горячих клавиш

> **Hintsage AI Interview Assistant** - Полный список всех горячих клавиш для удобной работы

---

## 🌍 ГЛОБАЛЬНЫЕ ГОРЯЧИЕ КЛАВИШИ

Эти клавиши работают **в любом приложении**, независимо от того, активно ли окно Hintsage.

| Горячая клавиша | Действие | Описание | Архетип |
|----------------|----------|----------|---------|
| **Ctrl+Shift+H** | 🔄 Toggle Overlay | Свернуть/развернуть окно Hintsage | [ЧЕЛО + ЛИЧЬ] |
| **Ctrl+Shift+Q** | ⚡ Manual Trigger | Вручную активировать обработку вопроса | [ЧЕЛО] |
| **Ctrl+Shift+S** | 📸 Screenshot Area | Сделать скриншот области экрана для OCR | [ВЕДИ] |
| **Ctrl+Shift+C** | 🧹 Clear Context | Очистить контекст и историю диалога | [ПАМЯТЬ] |
| **Ctrl+Shift+X** | ❌ Exit | Безопасный выход из приложения | [НАВЬ] |

---

## 🖥️ ЛОКАЛЬНЫЕ ГОРЯЧИЕ КЛАВИШИ

Эти клавиши работают **только когда окно Hintsage активно**.

| Горячая клавиша | Действие | Описание | Архетип |
|----------------|----------|----------|---------|
| **Esc** | 👻 Hide Window | Скрыть окно (но не закрыть) | [ЛИЧЬ] |
| **Ctrl+Q** | 🚪 Close Window | Полностью закрыть окно приложения | [НАВЬ] |

## 🛠️ НАСТРОЙКА ГОРЯЧИХ КЛАВИШ

Вы можете изменить горячие клавиши в файле **`config.yaml`**:

```yaml
# Hotkeys [ЧЕЛО + ПУТЬ]
hotkeys:
  toggle_overlay: "ctrl+shift+h"    # Сворачивание/разворачивание
  manual_trigger: "ctrl+shift+q"    # Ручной триггер
  screenshot_area: "ctrl+shift+s"   # Скриншот области
  clear_context: "ctrl+shift+c"     # Очистка контекста
  exit: "ctrl+shift+x"              # Выход
```

### Поддерживаемые модификаторы:
- `ctrl` - Ctrl
- `shift` - Shift  
- `alt` - Alt
- `win` - Win (Windows key)

### Примеры комбинаций:
- `ctrl+alt+q`
- `shift+alt+h`
- `ctrl+shift+alt+s`

## 💡 СОВЕТЫ ПО ИСПОЛЬЗОВАНИЮ

### 🎯 Рекомендуемый workflow:

1. **Запуск интервью:**
   - Приложение автоматически слушает вопросы
   - Окно всегда поверх других окон

2. **Во время вопроса:**
   - `Ctrl+Shift+H` - свернуть окно, если мешает
   - `Ctrl+Shift+Q` - вручную запустить обработку (если автоопределение не сработало)
   - `Ctrl+Shift+S` - сделать скриншот текста вопроса для OCR

3. **Получение ответа:**
   - Ответ появляется в окне
   - `Esc` - скрыть окно после прочтения
   - `Ctrl+Shift+H` - вернуть окно обратно

4. **Между вопросами:**
   - `Ctrl+Shift+C` - очистить контекст для нового вопроса
   - Контекст сохраняется автоматически между вопросами

5. **Завершение:**
   - `Ctrl+Shift+X` - безопасный выход
   - История сохраняется в `data/sessions/`

### 🔒 Режим "Фантом" (Phantom Mode):
- Окно прозрачно для мыши
- Не перехватывает клики
- Можно кликать "сквозь" окно на приложения под ним

### 🛡️ Антидетект функции:
- Окно не захватывается скриншотами (Windows 10 2004+)
- Не показывается в панели задач
- Не крадет фокус от других окон

## 🐛 TROUBLESHOOTING

### Горячие клавиши не работают?

1. **Проверьте конфликты:**
   - Возможно другое приложение использует те же клавиши
   - Попробуйте изменить в `config.yaml`

2. **Права администратора:**
   - Некоторые приложения блокируют глобальные hotkeys
   - Попробуйте запустить Hintsage от имени администратора

3. **Модуль keyboard:**
   ```bash
   pip install keyboard>=0.13.5
   ```

4. **Windows безопасность:**
   - Разрешите доступ к клавиатуре в настройках безопасности

### Окно не разворачивается?

- Проверьте логи: `logs/hintsage.log`
- Попробуйте `Esc` для скрытия, затем `Ctrl+Shift+H` для показа
